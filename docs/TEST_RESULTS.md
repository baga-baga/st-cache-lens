## 0.1.11 连接失败原因与候选地址

- 修正直接连接仅使用第一个 DNS 地址：全部结果通过既有校验后，固定候选集交给 Node 连接选择。只在 TCP 建连阶段使用其他候选，不重新发送生成 POST，不增加 Agent 预算调用次数，不改变 TLS、重定向、私网及 Fake-IP 边界。
- 网络错误保留白名单原因、阶段、连接方式、有界时长及是否可能已发送的状态；通过服务端 HTTP、记录与前端诊断链路保留，同时过滤任意异常正文、URL、地址、证书和凭据。旧记录没有的数据不会补造。
- 回归覆盖 GET 查询成功后 POST 连接被断开、不同阶段连接失败、候选地址选择、TLS 拒绝、正文中断与记录脱敏。全套 439 项通过，77 个 JS/MJS 语法检查通过；测试上游均在本机，未产生真实模型费用。
- 前端和服务端均需更新至 0.1.11。安装只同步插件程序，不改世界书、预设、已保存密钥或费用台账。未知 usage 不按零计费、不退回预留，不自动重试失败请求。
- 用户提供的两个错误码未包含底层原因，不能断言其由地址选择、Clash 或 TLS 的某一种故障造成。测试未使用真实 OpenAI Key 或用户手机，没有真实付费调用，也没有确认实际 API 或缓存改善。

## 0.1.10 失败证据保留与免费恢复

- 审计失败保留固定白名单错误码、批次、执行阶段，以及可确认的酒馆 HTTP / 上游 HTTP 状态。调用后复核失败与模型调用失败区分，不导出任意异常正文、堆栈、地址或密钥。
- 采集问题代码、世界书期望/已读数量、角色选择状态、请求原文可用数量进入有界报告，并在分页前计入 18KB 大小限制。零世界书不被解释为文件删除。
- 未选角色、必要绑定未知、世界书读取失败及截断会在付费全面检查前停止；合法空书列表、没有历史原文、预设顺序未知及未知扩展只读不会单独阻止配置检查。
- 新增“读取失败原因与采集状态（免费）”：仅重新本机采集并 GET 读取既有服务端状态与 Agent 记录，预算为 0 也可用。保留最多 10 条失败摘要，说明 usage 计价与费用预留区别；历史记录不自动匹配上传的旧报告，不重试、不重置预算、不退款。
- 27 项新增测试覆盖安全错误与阶段导出、采集缺口、已知空书/无原文、不含私密正文的历史恢复、零预算免费入口、浏览器网络/JSON 错误及已有记录不可读时仍可导出本机证据。全套 418 项通过，74 个 JS/MJS 语法检查通过。
- 0.1.10 当时服务端代码不变，沿用 0.1.9；该历史结论不适用于 0.1.11 网络修复。当前用户旧报告没有具体失败码，不能由本轮测试倒推出其真实 API 错误或实际扣费；没有额外真实模型调用。原上传文件未加入源码或测试素材。

## 0.1.9 沿用现有网络的 Fake-IP 兼容

- 普通 HTTPS 请求针对精确官方 origin `https://api.openai.com:443` 接受 DNS 返回的 `198.18.0.0/15`，固定本次解析结果并交由系统现有路由连接，无需手动代理端口。该范围仍不被归类为公网；不是检查用户公网出口 IP。
- 请求固定官方 Host / TLS SNI，并显式启用证书验证。其他域名、端口、HTTP、数字 IP URL、其他私网范围、Fake-IP 与私网混合解析和重定向仍拒绝。不会修改 DNS、Clash 配置或添加直连回退。
- 代理/网络测试从 18 项增至 28 项。新增真实本地 TLS 测试覆盖无代理设置下的 Agent GET 检查及预算受控 POST、DNS 固定、正常公网结果、错误证书与错误域名；即使测试进程禁用全局 TLS 检查并伪造 Host，生产请求选项仍阻止未验证连接。测试侧模拟系统转发，没有生产测试后门。
- 手动代理移至可选折叠区；保留既有显式选择并显示已保存/当前连接方式。已保存代理会展开显示，用户可关闭并保存后沿用设备网络。
- 此修正位于共享网络函数，亦覆盖上游为该精确官方地址的 relay；其他域名不获例外。自定义 Fake-IP 网段、IPv6 Fake-IP 及用户设备实际网络尚未验证，不能声称所有网络均可用。
- 391 项测试、70 个源码语法检查、官方酒馆 1.19.0 的 10 项 HTTP 集成检查通过；零真实付费调用。仍需同步 0.1.9 服务端组件，此结果不证明用户真实 OpenAI 连接或 Claude 缓存费用已改善。

## 0.1.8 Clash HTTP / Mixed 代理

- 新增显式本机 HTTP CONNECT 代理，仅支持官方 OpenAI HTTPS 目标；直接连接的私网地址校验保持不变。目标域名不在酒馆进程内解析，不更改 Clash DNS / Fake-IP 设置，不会在失败后回退直连。
- 18 项代理测试通过：真实本机 CONNECT 与独立测试 CA 验证的 TLS、目标 DNS 零查询、CONNECT 不携带 API 密钥、错误证书和错误域名拒绝、代理认证/拒绝、重定向拒绝、超时/取消/截断正文及连接清理。AgentService 的模型 GET 和预算受控 POST 均通过隧道验证。
- 配置保存/重新载入保留密钥与已用预算，代理只随相同接口继承；显式空值关闭，错误路由在预算预留前拒绝。原 relay 不读取该代理配置。
- 挂载界面覆盖默认关闭、旧服务端兼容与开启时更新提示、代理检查/保存/关闭、手动输入保护，以及先快捷填写再检查时恢复同接口已保存代理。
- 服务端单独升级测试确认用户密钥、费用台账和前端 Git 安装不被覆盖。此次新增服务端功能需要同步组件并重启，单独更新前端不能启用它。
- 全套测试中修正一处旧 UI 测试的固定 25ms 等待，改为等待操作完成，避免并行执行时提前断言；最终 381 项通过。
- 开发测试额外需要 `openssl` 命令生成临时证书；插件运行没有新增依赖。未实测用户手机、实际 Clash 端口或真实 OpenAI 凭据，没有付费调用，不能据此宣称用户已经连通或缓存费用下降。

## 0.1.7 检查按钮与有界等待

- 连接检查在请求开始前显示状态；前置校验错误同时显示在当前检查区域与按钮附近，不再只有面板顶部可见。
- 初始化等待、只读配置采集、API 响应及正文读取有期限；超时不重试。扫描结果迟到不会覆盖后续报告，已发出的付费调用仍可能由服务端计费。
- 初始采集即可取消；停止和取消排队不会稍后自动启动 Agent。
- 修正没有请求原文时的 null/undefined 比较：设置检查可正常执行，实际请求和缓存证据缺口仍明确保留。
- 新增 8 项挂载界面测试与 2 项等待控制测试，覆盖无响应正文、迟到结果、初始化锁等待、重复点击、局部报错和零新增剧情请求。没有真实付费调用。

## 0.1.6 Agent 分页检查与作用域修正

- 一键重新采集当前绑定书、预设、公开扩展来源及有界观察记录；完整设置元数据分页进入既有 Agent 服务，不再依赖被裁剪的摘要。每批最多 18KB、数组最多 80 行，经过旧版服务端脱敏仍保留全部行。
- 473 条世界书、87 项预设、15 个扩展来源的合成覆盖与实际报告分页核对通过；实际报告默认需 6 批检查加 1 次汇总。没有调用用户真实模型，也没有上传其报告到测试上游。
- 默认排除正文、私有名称、触发词和凭据；局部正文需独立勾选，最多 10 段、每段 600 字符。已覆盖引号、转义、截断边界和 URL 凭据脱敏。
- 整次调用次数与费用预检、服务端逐次预留、用户停止、配置失效、模型越权输出、失败后不自动重试都有测试；停止不撤销已经发生的计费。
- 最终 Agent 只能选择本地已经校验的候选。界面先显示预览，应用前再次读取配置，检测并发变化；既有应用、请求转换与关联设置回滚测试通过。
- 固定位置 0/1/2/3/5/6 忽略并不生效的条目 role/depth/outlet 元数据；依据官方 1.19.0 world-info.js 的注入分支。实际消息角色、路径、位置、外层标签以及按深度注入的有效字段仍严格核对。
- 实际 AgentService 0.1.1 与本地模拟 HTTP 上游的两项集成测试通过，因此本功能只需更新前端，不要求重装既有服务端。
- 全部验证使用合成请求或本机只读报告，没有新增真实付费调用。未验证实际用户模型输出质量、手机视觉效果、上游缓存读取或连续会话费用下降。其他未绑定角色、未知第三方内部状态与中转路由仍不可见。

## 0.1.4 诊断修正

- 候选拒绝原因按固定代码和中文分类显示；设置报告导出候选状态、计数、保护原因及有界脱敏条目引用。任意错误正文、原文、私人名称和未识别字段不进入候选摘要。
- 已精确匹配的世界书仍可能被结构保护排除；零候选不再被解释成没有找到世界书。挂载界面测试覆盖两条已匹配内容因整消息围栏而被拒绝，并验证报告仍导出拒绝码。
- 未知扩展与预设顺序未知分开显示；预设顺序已知时不因未知扩展误报顺序未知。
- 派生预算显式标注 Cache Lens 配置上限的计算来源；200000 的参考值与酒馆扫描1970000独立保存，不冒充实际发送量。
- 没有放宽候选校验、改写原书或增加模型调用；没有测得真实缓存或费用改善。0.1.3旧报告不含拒绝明细，不能凭空补回。

## 0.1.3 新增覆盖

- 当前绑定书、预设与公开扩展来源只读收集；全局/角色/聊天/用户书去重，版本与覆盖未知保持明确，扫描期间改动或超限时拒绝优化。
- 批量报告区分整书、预算、激活与最终发送；比较按用途、模型、接口、聊天及观察层分组，Agent 摘要不含正文、私有名称和触发词。
- 一次授权后，仅重排本次真实激活、唯一定位、同消息和同作用域的完整世界书片段；跨卡使用新内容，不复用旧卡正文。
- 中文标签、空白和内容字节守恒；相对时间、状态、骰池、宏、跨标签或依赖文本不进入自动范围。只有关键词资料时不制造改动。
- 第三方适配器即使伪造官方事件名称也不获自动调整权限；运行时必须有当前生成的真实激活标记。
- 完整请求保守上界覆盖 150 万输入，估算值不能绕过；上界不是实际 tokens，合法长中文请求也可能被跳过。
- 13 项新挂载界面测试覆盖免费扫描、零预算拒绝 Agent、用途确认、跨卡跟随、过期扫描丢弃、请求期间延后、启用/回滚、并发冲突及手动策略互斥。
- 应用结果的版本/计数/状态跨刷新及脱敏导出保留；理由正文、名称及任意附加字段不进入存档。导入仍未核实，缺失 usage 不补零。
- 本轮没有真实模型调用。前端原生 GitHub 更新在发布后按实际提交单独复验；已有服务端组件无需为批量功能重装。

## 0.1.2 新增覆盖

## 实测的边界

真实运行的是酒馆宿主、HTTP 请求转发和本地插件逻辑。上游回复及 usage 是测试构造。没有测得你的 Claude 缓存读取、费用降低或剧情质量改善；不能将本报告当作这些结果的证明。

未实测：Android/Termux 实机、Windows/macOS 实机、你的正文和摘要模型账户、中转内部转换、尚未确认仓库/版本的酒馆助手/自动摘要/类脑缓存管理插件。Node 20 是实现兼容下限；本次执行版本为 Node 24。

## 在隔离副本复验

正常安装插件不需要这些开发依赖。开发复验：

```bash
npm ci --ignore-scripts
npm test
npm run check
npm run demo
```

完整宿主链路仅在新克隆的测试酒馆副本运行：

```bash
node scripts/verify-st.mjs --st /path/to/disposable/SillyTavern --isolated-test-copy
```

该命令会安装测试扩展并配置模拟观察器，不能指向正在游玩的正式酒馆目录。
